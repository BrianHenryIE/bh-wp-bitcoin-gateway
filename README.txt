Accept Bitcoin payments using self-custodied wallets, and no external account. Calculates wallet addresses locally and uses open APIs to verify payments. For an emphasis on privacy & sovereignty.

== Description ==

A Bitcoin gateway for WordPress that does not charge fees or every hold posession of your Bitcoin.

It currently uses public APIs for payment verification with some work (abstraction, RPC library) underway to allow more control over the blockchain instance used.

Thorough recording of wallets, payment addresses, and transactions in WordPress custom post types for complete visibility into system state, displayed in standard extensible WP List Tables.

Support for WooCommerce blocks checkout and thank you page (full site editing); support for legacy WooCommerce shortcode checkout via template files.
